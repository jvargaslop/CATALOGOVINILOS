# Dyler Music · Escarba el catálogo (demo de 10 discos)

## Publicar en GitHub Pages
1. Crea un repositorio nuevo en github.com (por ejemplo `dyler-music`), público.
2. Sube **todo el contenido de esta carpeta** (`index.html` y la carpeta `img`) a la raíz del repositorio.
3. En el repositorio: Settings → Pages → Source: *Deploy from a branch* → Branch: `main` / carpeta `/ (root)` → Save.
4. En 1 o 2 minutos queda en `https://TU-USUARIO.github.io/dyler-music/`.

## Poner tu WhatsApp
Abre `index.html`, busca la línea `const WA="";` y escribe tu número con indicativo, sin + ni espacios:
`const WA="573001234567";`
